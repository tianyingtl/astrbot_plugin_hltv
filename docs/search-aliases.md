# 名称与别名

战队、选手别名统一维护在 [core/aliases.py](../core/aliases.py)。
文件按正式名称分组，可直接查看每个名称支持的写法。

## 使用范围

- 战队：资料、直播筛选与订阅、Rating 回看、赛事数据榜、AI 资料查询。
- 选手：个人资料、赛事榜选手定位及高亮、AI 选手资料查询。
- 英文别名不区分大小写，常见空格与标点可省略。选手结果优先匹配准确昵称；当多个官方昵称仅大小写不同，优先采用输入的原始拼写。
- 已知战队别名只匹配对应战队。主队与青训队分别维护，不按阵容继承关系合并俱乐部。
- 未收录名称继续使用原词搜索。别名只负责名称转换，不保证历史资料或已结束赛事一定有数据。

历史战队包括 Gambit、Envy、Dignitas、Renegades、North、HellRaisers、
FlipSid3、Titan、VeryGames、SK、Luminosity、OpTic、Evil Geniuses 等。
简写存在明显歧义时，建议使用完整昵称或俱乐部名称。
